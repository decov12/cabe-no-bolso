# Feedback de usuários (tarefa do quadro: "Questionário de feedback")

Meta: pelo menos **10 pessoas** que não participaram do projeto testam o site no ar e respondem o formulário.

## Como aplicar

1. Mande o link do site (está no topo do [README](../README.md)) para a pessoa.
2. Peça que ela crie uma conta, faça **uma** simulação de uma viagem que realmente gostaria de fazer, abra as alternativas e depois responda o formulário (3 minutos).
3. Não explique nada antes. Se ela travar em algum ponto, anote onde. Isso também é resultado.
4. Cada pessoa gasta de 3 a 4 buscas da SerpApi (cota de 250 por mês), então combine os testes e evite repetir a mesma rota. O cache de 24 horas ajuda quando a rota é igual.
5. A primeira chamada do dia pode demorar cerca de 1 minuto (o servidor gratuito "dorme"). Avise a pessoa.

## Perguntas do formulário (Google Forms)

1. Você conseguiu fazer uma simulação sem ajuda? (sim / sim, mas com dificuldade / não)
2. O resultado ("cabe", "cabe com ajustes", "não cabe") ficou fácil de entender? (1 a 5)
3. Você confia nos valores mostrados? (1 a 5)
4. As alternativas para fazer a viagem caber ajudariam você a decidir? (1 a 5)
5. O total estimado ficou próximo do que você esperava para essa viagem? (muito abaixo / um pouco abaixo / próximo / um pouco acima / muito acima)
6. Alguma parte demorou ou confundiu? Qual? (texto livre)
7. O que você mudaria primeiro? (texto livre)
8. Você usaria o site para planejar uma viagem de verdade? (sim / talvez / não)
